#Instructions

1. From start.html in the blog folder, use the img element to link to end.png
1. From the start.html in the blog folder, use the link element to link to end.ico. Don't forget rel="icon"
1. From start.html in the blog folder, use the script element to link to end.js. Use the src attribute
1. From start .html in the blog folder use the img element to link to end.png. Use the src attribute.
1. From start.html use the anchor element to link to the end folder. Use the href attribute.
1. From start.html use the audio element to link to end.mp3. Use the src attribute and the controls attribute.
1. From index.html use the anchor element to link to the end folder. Use the href attribute.
1. From start.html use the anchor element to link to the index.html file in the root. Go up two folders using double dots and the file name.
1. From index.html in the end folder use the anchor element to link to index.html in the root. Go up three folders using double dots and the file name.
1. From audio.html use the video element to link to earth.mp4 in the video folder. Use the src attribute.
1. From video.html use the anchor element to link to index.html in the root. Use the href attribute. Two ways of doing this. Try root relative path /.
